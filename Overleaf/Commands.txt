One-shot pull (Overleaf → local)
python sync_courses.py --pull

One-shot push (local → Overleaf)
python sync_courses.py --push

Pull and push mirror the other side. Any file missing on the source side gets a prompt:
  d = delete it (on pull, the matching .pdf and any emptied folders are removed too; deleted files skip the Recycle Bin)
  r = restore it to the source side
  i = ignore (leave it alone this time)
Files matching .olignore are never synced or deleted in either direction.
desktop.ini, *.pyc, __pycache__, .olauth and .olignore are always ignored, even if .olignore is missing.
Two-way sync (no flag) and the background daemon never delete anything.
A failed file is reported at the end and does not stop the rest of the sync.
The sync client is vendored in .\olsync (patched copy), so pip upgrades of overleaf-sync do not affect it.

Ctrl+S in this workspace (LaTeX Workshop onSave)
Compiles the open .tex (PDF tab stays on the temp copy), then copies it to the mirrored
Overleaf/.pdf/... path. Missing folders under .pdf are created on that save.
If the .tex is empty (or only whitespace), the mirrored PDF is deleted instead of compiling.
Does not run a background watcher. Aux cleaning uses glob, not latexmk/Perl.
