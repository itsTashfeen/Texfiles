\section*{\textbf{1. Find the probabilities that the time between two accidents happen within 1, 2, 3 standard deviations from the mean (44 days).}}

From Example 2, the time between accidents $Y$ follows an exponential distribution with mean $\mu = \beta = 44$ days. For an exponential distribution, the standard deviation is equal to the mean, so $\sigma = \beta = 44$ days.

I calculate the probabilities using the cumulative distribution function (CDF) for an exponential random variable, $F(y) = 1 - e^{-y/\beta}$ for $y \ge 0$.

For 1 standard deviation:
$$P(|Y - \mu| \le 1\sigma) = P(44 - 44 \le Y \le 44 + 44) = P(0 \le Y \le 88)$$
$$= F(88) - F(0) = (1 - e^{-88/44}) - (1 - e^0) = 1 - e^{-2} \approx 0.8647$$

For 2 standard deviations:
$$P(|Y - \mu| \le 2\sigma) = P(44 - 88 \le Y \le 44 + 88) = P(-44 \le Y \le 132)$$
Since $Y \ge 0$, this becomes $P(0 \le Y \le 132)$:
$$= F(132) - F(0) = 1 - e^{-132/44} = 1 - e^{-3} \approx 0.9502$$

For 3 standard deviations:
$$P(|Y - \mu| \le 3\sigma) = P(44 - 132 \le Y \le 44 + 132) = P(-88 \le Y \le 176)$$
Since $Y \ge 0$, this becomes $P(0 \le Y \le 176)$:
$$= F(176) - F(0) = 1 - e^{-176/44} = 1 - e^{-4} \approx 0.9817$$

\section*{\textbf{2. Prove the variance formula for the Beta distribution} $V(Y) = \frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$.}

I use the variance formula $V(Y) = E(Y^2) - [E(Y)]^2$. The probability density function for a Beta distribution is $f(y) = \frac{y^{\alpha-1}(1-y)^{\beta-1}}{B(\alpha,\beta)}$ for $0 \le y \le 1$.

First, I find $E(Y^2)$:
$$E(Y^2) = \int_{0}^{1} y^2 \frac{y^{\alpha-1}(1-y)^{\beta-1}}{B(\alpha,\beta)} dy = \int_{0}^{1} \frac{y^{\alpha+1}(1-y)^{\beta-1}}{B(\alpha,\beta)} dy$$

I rewrite the integral in terms of the Beta function:
$$E(Y^2) = \frac{B(\alpha+2, \beta)}{B(\alpha,\beta)}$$

Using the property $B(\alpha,\beta) = \frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}$, I expand the expression:
$$E(Y^2) = \frac{\frac{\Gamma(\alpha+2)\Gamma(\beta)}{\Gamma(\alpha+\beta+2)}}{\frac{\Gamma(\alpha)\Gamma(\beta)}{\Gamma(\alpha+\beta)}} = \frac{\Gamma(\alpha+2)\Gamma(\alpha+\beta)}{\Gamma(\alpha+\beta+2)\Gamma(\alpha)}$$

I apply the property $\Gamma(x+1) = x\Gamma(x)$ to simplify the gamma functions:
$$E(Y^2) = \frac{(\alpha+1)\alpha\Gamma(\alpha)\Gamma(\alpha+\beta)}{(\alpha+\beta+1)(\alpha+\beta)\Gamma(\alpha+\beta)\Gamma(\alpha)} = \frac{\alpha(\alpha+1)}{(\alpha+\beta)(\alpha+\beta+1)}$$

Next, I substitute $E(Y^2)$ and $E(Y) = \frac{\alpha}{\alpha+\beta}$ into the variance formula:
$$V(Y) = \frac{\alpha(\alpha+1)}{(\alpha+\beta)(\alpha+\beta+1)} - \left( \frac{\alpha}{\alpha+\beta} \right)^2$$

I find a common denominator of $(\alpha+\beta)^2(\alpha+\beta+1)$ for the terms:
$$V(Y) = \frac{\alpha(\alpha+1)(\alpha+\beta) - \alpha^2(\alpha+\beta+1)}{(\alpha+\beta)^2(\alpha+\beta+1)}$$

I expand the numerator:
$$= \frac{\alpha(\alpha^2 + \alpha\beta + \alpha + \beta) - (\alpha^3 + \alpha^2\beta + \alpha^2)}{(\alpha+\beta)^2(\alpha+\beta+1)}$$
$$= \frac{\alpha^3 + \alpha^2\beta + \alpha^2 + \alpha\beta - \alpha^3 - \alpha^2\beta - \alpha^2}{(\alpha+\beta)^2(\alpha+\beta+1)}$$

Canceling the terms, I get the requested result:
$$V(Y) = \frac{\alpha\beta}{(\alpha+\beta)^2(\alpha+\beta+1)}$$
